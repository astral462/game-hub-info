# 🎮 GameHub

## 📌 Опис проєкту

**GameHub** — це графічний Python-додаток для пошуку інформації про безкоштовні відеоігри.

Програма використовує **FreeToGame API** для отримання інформації про ігри та **CustomTkinter** для створення графічного інтерфейсу.

Користувач вводить назву гри у поле пошуку, після чого програма надсилає запит до API та показує знайдену інформацію.

---

## 🎯 Мета проєкту

Метою проєкту є практичне використання:

* API Calls;
* CustomTkinter;
* об'єктно-орієнтованого програмування (ООП);
* бібліотеки Requests;
* бібліотеки Pillow.

---

## ⚙️ Використані технології

### Python

Основна мова програмування проєкту.

### CustomTkinter

Використовується для створення графічного інтерфейсу програми.

За допомогою CustomTkinter створені:

* вікно програми;
* кнопки;
* поле пошуку;
* текстове поле;
* інформаційні повідомлення;
* область для зображення.

### Requests

Використовується для надсилання HTTP-запитів до API.

Приклад:

```python
response = requests.get(
    f"{self.api_url}/games",
    timeout=10
)
```

### Pillow

Використовується для завантаження та відображення зображень ігор.

### FreeToGame API

API використовується як джерело інформації про безкоштовні відеоігри.

API не потребує API-ключа.

---

# 🧠 ООП у проєкті

У програмі використовується об'єктно-орієнтоване програмування.

## Клас `Game`

Клас `Game` зберігає інформацію про конкретну гру.

Він містить:

* назву;
* опис;
* жанр;
* платформу;
* розробника;
* видавця;
* дату випуску;
* зображення.

Метод:

```python
from_api()
```

перетворює дані, отримані від API, на об'єкт класу `Game`.

---

## Клас `GameAPI`

Клас `GameAPI` відповідає за роботу з API.

Він містить методи:

```python
search_game()
```

Використовується для пошуку гри.

```python
get_game()
```

Отримує детальну інформацію про конкретну гру.

Таким чином, робота з API відокремлена від графічного інтерфейсу.

---

## Клас `GameHub`

Клас `GameHub` відповідає за графічний інтерфейс програми.

Він керує:

* створенням вікна;
* полем пошуку;
* кнопкою пошуку;
* відображенням інформації;
* відображенням зображення;
* повідомленнями про помилки.

---

# 🔄 Як працює програма

Процес пошуку виглядає так:

```text
Користувач
     ↓
Вводить назву гри
     ↓
Натискає "ПОШУК"
     ↓
GameHub
     ↓
GameAPI
     ↓
FreeToGame API
     ↓
Отримання JSON
     ↓
Game.from_api()
     ↓
Створення об'єкта Game
     ↓
Відображення інформації
```

# 🌐 API

У програмі використовується FreeToGame API.

Основна адреса API:

```text
https://www.freetogame.com/api
```

Для пошуку ігор використовується:

```text
https://www.freetogame.com/api/games
```

Для отримання інформації про конкретну гру:

```text
https://www.freetogame.com/api/game?id=ID
```

API-ключ для роботи програми не потрібен.

---

# 🛡️ Обробка помилок

У програмі передбачена обробка помилок.

Наприклад, якщо немає підключення до Інтернету:

```python
except requests.RequestException:
```

користувач побачить повідомлення:

```text
❌ Помилка підключення.
Перевірте підключення до Інтернету та спробуйте ще раз.
```

Якщо гра не знайдена:

```text
❌ Гру не знайдено.
Спробуйте ввести іншу назву.
```
